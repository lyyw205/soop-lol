# 전달 형식과 평가 기준

## 파일과 책임

| 파일 | 용도 |
| --- | --- |
| `source-scan.json` | 기존 ck-local 준비 결과의 비교 기준 스냅샷 |
| `scan.json`, `frames/` | 후보를 보존한 실험용 프레임 입력 |
| `transcript-input.json` | 원문 ASR·실제 전사 범위·출처 해시 |
| `selection.json` | 모델이 고른 원문 ID, 처리/실패 범위, 재전사 요청 ID |
| `vision.json` | 선택적으로 실행한 화면 종류·가시성 분류, 미판독 목록 |
| `handoff.json` | Claude 기본 입력: 시간순 전사 원문 클립·앞뒤 문맥·경기별 원본 |
| `packet.json` | 원문까지 포함한 전체 근거 조회용 자료 |
| `report.html` | 사용자 검토 화면 |
| `metrics.json` | 단계 시간·로컬 모델 입력/출력 토큰·캐시·전달 크기 |

형식은 `ck-context/v2-selection`이다. 이전 해석 실험의 출력은 새 실행 폴더와 분리한다.
선별 모델의 출력은 `selected_ids`, `recheck_ids`뿐이다. claim·화자·합의 여부·이름·카테고리·요약 필드는 허용하지 않는다.
`handoff.json`의 클립은 `at`, `end`, `selected_ids`, `source_ids`로 원문을 연결한다. 전사 문장은 프로그램이 그대로 복사한다.
앞뒤 30초 문맥을 포함하고 겹치는 클립은 합친다. ASR 시각은 조각 경계이며 단어 단위 정렬이 아니다.
선별되지 않은 대화도 `packet.json`에는 남는다. 실패 구간은 미처리로 표시하며 대본 전문을 자동 전달하지 않는다.
모델 생성 요약·OCR·추론·원시 로그는 기본 전달에 없다. 추가 이미지 선별의 분류값도 기본 전달에는 넣지 않는다.

각 후보에는 대표·대체 원본, 인접 원문 클립, 기존 판별기의 밴픽/로비 위치를 함께 넣는다.
대표 원본은 이미지 모델이 읽기 좋다고 본 것이 있으면 우선 제시하되 모든 원본과 후보를 보존한다.
인접 클립 연결은 직전 30분의 시간 근접 제안이다. 초반 합의가 더 오래 적용될 수 있으므로 시간순 클립 목록도 검토한다.

## 비교

1. **판독 품질 보존:** 동일 VOD의 기존 후보 번호·시각·원본 해시가 그대로인지 비교한다. 참가자·KDA·승패 값은 기존 결과와 대조한다.
2. **선별 재현율:** 별도로 확인한 모집·진행형식·규칙·팀/포지션 변경·종료의 근거 구간이 전달됐는지 센다. 가장 중요한 실패는 핵심 근거 누락이다.
3. **전달 효율:** 관련 없는 원문 비중과 전달한 초/문자 수를 센다. 대부분의 전사를 전달하면 선별 이득이 작다. 전사 오류를 선별 모델 오류와 구분한다.
4. **최종 비용·품질:** 동일 VOD의 기존 조사와 Claude 실제 사용량·최종 정확도를 비교한다. 바이트 감소를 토큰/API 비용 감소라고 부르지 않는다. 더 많은 재조회나 오류 수정이 필요하면 채택하지 않는다.
5. **새 자료:** 기존 55분은 개발 표본이다. 같은 표본에 맞춘 뒤 성능 검증이라고 하지 말고 별도 VOD로 확인한다.

규칙형 위험 사례: 300개는 판 수가 아님, 강화 6회는 6경기가 아님, 과거 CK 언급은 현재 CK 확정이 아님,
타인 솔랭 중 발언은 본인 솔랭 시작이 아님, 로비 줄 이동과 포지션 변경은 다름.
모델 입력에는 사례의 실제 정답이나 어시스턴트가 만든 정답 사건 목록을 제공하지 않는다.

## 코드 경계

- `frames.mjs`: 기존 준비 결과 읽기/복사 또는 같은 판별기의 독립 실행. 기존 실행·기록 CLI를 호출하지 않는다.
- `audio.mjs`: 제한된 크기의 음원 확보, 기존 ASR 실행기 재사용, 전사/시간축 검증.
- `model.mjs`: 로컬 서버 관문, 모델 digest 기반 캐시, 구조화 출력, 실제 사용량 기록.
- `select.mjs`: 원문 ID 선별·참조 검사·문맥 확장·선택적 이미지 분류·재전사 범위 제한.
- `packet.mjs`: 후보와 근거 연결·기계 검증·전달/검토 화면 생성.
- `cli.mjs`: 명령 조립과 단계별 실행. 도메인 판정·DB 저장을 섞지 않는다.
