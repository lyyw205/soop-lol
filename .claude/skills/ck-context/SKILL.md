# CK 음성·맥락 실험

목적은 기존 참가자·승패·KDA 판독 품질을 유지하면서 포지션·카테고리·시리즈 누락을 줄이는 것이다.
기존 수준의 Claude 비용은 허용한다. 로컬 모델의 역할은 **어떤 자료를 전달할지 선택하는 것**이다.
화자·카테고리·포지션·합의·적용 경기를 해석하거나 요약한 문장을 Claude에게 검증시키지 않는다.

## 운영과 분리

- 운영 `ck-local`, 판별기 가중치, 자동 조사·큐·타이머 설정을 바꾸지 않는다.
- 도구: `node scripts/ck-context/cli.mjs`. 출력: `out/ck-context/<vod>/<run>/`.
- 기존 `scan.json`·프레임은 읽고 복사한다. 후보 번호·시각·원본 픽셀을 유지한다. 로컬 라벨로 후보를 제거하지 않는다.
- 시험은 DB 저장·FC 단서 등록·운영 검수 라벨 기록 없이 수행한다. 실제 반영을 사용자가 별도로 요청하면 기존 저장 창구를 사용한다.
- 새 모델 서버는 별도 포트 11439, 모델은 `.local/ck-context/`에 둔다. 운영 Ollama·ASR 환경을 교체하지 않는다.

## 실행

환경 준비 또는 첫 실행에는 [실행 안내](references/running.md)를 읽는다.

1. VOD와 비교할 기존 조사 결과를 정한다. 기존 `scan.json`을 쓸 수 있으면 그 후보·원본을 기준으로 삼는다.
2. `prepare`로 프레임 자료를 복사하거나 독립 준비한다. 새 모델은 같은 판별기 출력을 보충한다.
3. `run`을 한 작업으로 실행한다. 전체 음성 확보·전사 → 관련 원문 ID 선별 → 앞뒤 문맥·프레임 연결 → 전달 자료 생성을 프로그램이 진행한다.
   `--transcript`는 기존 표본 재사용이며 전체 방송을 분석한 것으로 보고하지 않는다.
4. 완료 후 `handoff.json`부터 읽는다. 전체 대본·모델 중간 출력·로그를 기본 컨텍스트에 넣지 않는다.
   필요한 원문은 `evidence --out 실행폴더 --id 근거ID`로 가져온다. 이미지 경로는 직접 열어 확인한다.
5. 기존 경기 판독을 수행하면서 시간순 원문과 해당 경기의 발언·화면 근거를 함께 검토한다.
   결과는 실험 폴더에 기록하고, 운영 `ck:local --review`, `--finish`, `ck:merge`를 시험 중 호출하지 않는다.

## 판단 계약

- 선별 모델은 원문 ID만 출력한다. 프로그램이 전사 원문·시각을 붙인다. 이름 교정·사건 요약·확정값을 생성하지 않는다.
- 선택 조각의 앞뒤 30초를 함께 전달하고 겹치는 원문은 한 번만 넣는다. 반박·거절·정정을 잘라내지 않았는지 확인한다.
- 전달 문장은 수정하지 않은 ASR 결과다. 실제 발화를 완벽히 옮겼다는 뜻은 아니며 오인식 가능성은 남는다.
- 게임·시점·주체, 제안·합의·실제 진행·과거 회고는 Claude가 근거로 판단한다. 초반 합의를 끝까지 자동 적용하지 않는다.
- 참가자·KDA는 기존처럼 원본에서 읽는다. 포지션과 진행 형식은 관련 발언과 밴픽·로비·메모를 대조한다.
- 구간의 경기별 연결은 시간 근접 힌트다. 정확한 적용 첫 경기와 종료 범위는 검토자가 확인한다.
- 원문 ID 밖의 참조와 모델이 작성한 해석 필드는 도구가 거부한다. 관련 구간을 빠짐없이 골랐다는 뜻은 아니다.
- 선별 실패 범위는 공개한다. 실패 시 전체 대본을 자동 투입하거나 없던 사건으로 처리하지 않는다.
- 선택되지 않은 원문도 전체 packet에 남긴다. 선별되지 않음과 중요하지 않음을 혼동하지 않는다.
- 추가 이미지 모델은 기본 꺼져 있다. 켜면 화면 종류·가시성만 분류하며 OCR/사실 요약은 전달하지 않는다.
- CK·랜드·보너스·칼바람·타인 방송의 의미 판단은 기존 [ck-research](../ck-research/SKILL.md)의 해당 절을 참고한다.
  이 시험에서는 그 스킬의 운영 저장 절차를 실행하지 않는다.

## 평가

[전달 형식과 평가 기준](references/contract.md)에 따라 비교한다.
[실험 기록](references/pilot-20261012.md)의 마지막 「원문 ID 선별 시험」 절에서 현재 모델의 채택 여부를 확인한다.
같은 문서 앞부분은 이전 해석 방식의 실패 기록이다. 그 수치를 현재 선별 방식의 성능으로 사용하지 않는다.
평가는 중요 구간 누락, 불필요한 구간 전달, 문맥 보존, Claude의 실제 사용량·최종 정확도로 한다.
올바른 자료만 읽는 비용보다 모델의 오판을 검증·수정하는 비용이 커지는 구성을 채택하지 않는다.
실제 실행하지 않은 모델 판정이나 전체 VOD 분석을 했다고 보고하지 않는다.
