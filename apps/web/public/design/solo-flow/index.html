뜨교듀오 / DESIGN REVIEW 02

승패 흐름을 읽는 세 가지 방식

실제 수집된 109경기 · 13일 · 56승 53패를 동일하게 적용한 인터랙티브 시안

기존 디자인 진단 · 무엇을 바꿨는가 8개 항목 ＋
  1. 중심이 없는 헤더. 전체 전적, 현재 연패, 최장 기록이 모두 같은 크기로 경쟁합니다. 가장 먼저 볼 수치를 하나 정하고 나머지는 보조 정보로 내립니다.
  2. 중복되는 수직 공간. 요약 아래 여백, 제목 행, 날짜 행이 연속되어 정작 그래프가 늦게 시작됩니다. 헤더를 통합하고 날짜는 얇은 독립 행으로 둡니다.
  3. 과도한 연승·연패 라벨. 모든 굴곡의 주석이 데이터를 덮습니다. 최고·최저·현재만 기본 표시하고 상세값은 선택해서 읽습니다.
  4. 불균일한 경기 간격. 날짜별 최소 너비가 경기 수와 섞여 같은 한 경기의 폭이 달라집니다. A는 경기당 동일 간격, B는 날짜당 동일 간격, C는 경기당 동일 타일을 사용합니다.
  5. 애매한 색상 의미. 파란 선이 모든 결과에 쓰이고, 보라색 끝점에는 설명이 없습니다. 승리·패배와 선택 상태를 명확히 구분합니다.
  6. 날짜 표와 그래프의 분리. 짙은 사각형 날짜 행이 선 그래프보다 먼저 보입니다. 축은 낮은 대비로, 선택한 날짜만 밝게 표시합니다.
  7. 모바일에서 최신 결과가 보이지 않음. 전체 폭을 그대로 스크롤하는 대신 A는 최근 경기부터, B는 선택한 날짜와 요약부터, C는 세로로 재배치합니다.
  8. 장식이 데이터에 집중됨. 글자·선·끝점에 분산된 광택을 패널 배경과 주요 도형으로 옮깁니다. 수치와 보조 텍스트는 선명하게 유지합니다.

A 누적 곡선형

큰 흐름을 먼저 · 경기 간격 고정 · 선택한 경기만 상세 표시

참고: TradingView의 기준선 차트 — 0선을 기준으로 영역을 나누고, 커서가 선택한 값만 강조. 누적 승패의 굴곡을 가장 잘 읽는 안.

B 날짜별 승패 막대형

승리와 패배를 위아래로 · 하루 단위 비교 · 중계 화면의 대비

참고: Strava의 Training Log — 활동을 날짜 단위로 분리하는 구조를 참고. 해당 날짜의 경기량과 승패 비중을 가장 쉽게 비교하는 안.

C 경기 타일형

109경기를 한 판씩 · 연속된 색으로 승패 확인 · 링으로 전체 요약

참고: Apple Activity의 링과 활동 기록 — 선명한 링과 반복되는 작은 단위의 기록 방식에서 착안. 여기서 링은 목표 달성률이 아닌 실제 승패 비율을 표시.
