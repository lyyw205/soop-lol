2026-09-24 실측. DB는 읽기만 했고, 프레임은 `ck:probe`로 뽑아 실제로 열었다.

## 발견

1. **`matchDate`는 경기 종료(결과 확정) 시각이다 — 표본 2건 일치.**
   VOD 207643193(등록 19:08:56 KST, HLS 실측 42:17 → 시작 ≈18:26:39)에서:
   - matchDate 18:51:35 경기: 18:49:09 지점에 인게임 67:35 (2:3), **18:51:18 지점에 인게임 88:23 (3:4)**,
     18:53:19 지점엔 다음 경기 대기실. → matchDate가 시작이라는 가설은 기각된다
     (시작이라면 matchDate 16초 전에 88분일 수 없다).
   - matchDate 19:03:58 경기: **19:03:41 지점에 인게임 89:53 (1:3)**, API 최종 1:4
     (추가시간 1골로 정합). 19:01:39 지점은 71:05.
   - 근거 프레임: `out/ck/207643193/g0001479.jpg`(88:23), `g0002222.jpg`(89:53), `g0001600.jpg`(대기실).
2. **경기 하나의 실제 벽시계 길이는 ≈9~12분.** 대기실 설정 화면에 `경기 시간 8분`이 보였고,
   연속 경기의 matchDate 간격(같은 상대 연전)은 10~12분이다.
   → 후보 시간창의 합리적 초기값: **경기 구간 ≈ [matchDate−12분, matchDate]**. 판정 규칙이 아니라 탐색 시작점이다.
3. **`등록시각 − HLS 실측 길이 = 방송 시작` 추정의 오차는 이 표본에서 ±1분 이내.**
   단일 파일 VOD였다. 분할·중단 VOD에서는 이 등식이 깨질 수 있는데(LoL에서 관측됨) FC 표본은 아직 없다 — 미관측.
4. **모드≠맥락 실증.** 두 경기 모두 API상 `40`(클래식 1on1, 친선 성격)이지만 실제로는
   고세구 주최 **"피온시식컵"** 경기였다(19:06:39 지점에서 김민교가 고세구 방송의 시식컵 로고 화면을 시청 중,
   `g0002400.jpg`). 매치 타입으로 단순 친선을 단정하면 이 대회가 통째로 친선이 된다.
5. **시청/중계 화면 사례.** `g0002400.jpg`는 본인 플레이가 아니라 브라우저로 남의 방송을 보는 화면이다.
   FC 화면이 보인다고 그 채널의 경기로 묶으면 안 되는 실물 사례.
6. **FC 방송의 SOOP 카테고리는 `40070`이다** (LoL은 `40019`). 위 표본 VOD 전부 40070.
   LoL 카테고리 필터를 일일 목록의 유일한 입력으로 쓰면 FC 방송이 전부 빠진다는 계획 전제가 실측으로 확인됐다.
7. **VOD 없음은 흔하다.** 9/23의 5경기는 세 채널 모두 해당 시각 VOD가 없다(등록된 VOD가 다른 시간대뿐).
   API 경기는 남고 맥락만 미확인 — 계획의 전제 그대로다.
8. **채널 미등록 사례.** `doochiwa-ppukku`는 FC 계정(`호날두`)은 연결됐지만 `streamer_channel`이 없다.
   이 사람 시점의 VOD 조사는 원천 불가하며, 이것은 `VOD 없음`과 다른 상태다(채널을 등록하면 풀린다).

## 한계

- matchDate=종료 결론의 표본은 2건이고, 같은 채널·같은 날·같은 모드다. 다른 모드(30·50·60)와
  다른 날짜에서 어긋나는 사례가 나오면 이 문서에 추가하고 시간창 초기값을 고친다.
- 분할·중단 VOD의 시간축 오차는 미관측. 처음 만나는 경우 실측을 여기 기록한다.
- 넥슨 매치 목록의 과거 조회 가능 범위(보존)는 별도 실측 항목이다 — 일일 수집 커서 설계의 입력.

## 추가 실측 — N커넥트 미니 뿌챔스 싸워 (2026-08-25, 오프라인 대회)

주최자 두치와뿌꾸 채널(galsa) VOD 205292057(16:00~20:04 KST)·205320949(20:04~00:15 KST) 판독.

1. **VOD 시간축을 프레임으로 보정했다.** VOD2 의 9600초 프레임이 `4위 결정전 이상호 0 : 1 스맵`
   인게임 화면인데, API 의 `22:44 스맵임(1):이상호(0)` 과 점수·시각이 맞는다 → VOD2 시작 = 20:04 KST.
   `등록시각 − HLS 길이` 추정과 1분 이내로 일치했다(중단 없는 방송).
2. **대회 공식 오버레이가 FC 감독명과 스트리머 이름을 나란히 띄운다.** 스쿼드 소개 화면에서
   `교로텔리·김민교`, `메시연·이상호`, `바르셀리아·스맵`, `호날두·두치와뿌꾸`, `불꽃열정·서도일`,
   `태민김·클리드`, `자므도·도현`, `잉유진·임유진` 8건을 모두 읽었다.
   **계정 매핑의 1급 근거**다 — 닉네임 추측이 필요 없다.
3. **★ API 가 대회의 전부를 담지 않는다.** 브래킷(VOD1 3300초)은 23경기 더블 엘리미네이션에
   `최종 결정전 (3판 2선)`이고, VOD2 13200·14400초에 결승 `임유진 vs 도현`(세트 0-1 → 1-1)이
   실제로 찍혀 있다. 그런데 **두 사람의 넥슨 매치 기록에는 23:22 이후 그날 경기가 없다.**
   오프라인 현장 계정으로 치른 것으로 보인다. → **「API 에 없으면 경기가 없었다」가 아니다.**
   대회 맥락 조사에서 VOD 는 API 를 보완하는 것이지 확인만 하는 것이 아니다.
4. 대회 시작(16:00) 전의 `스맵임 vs 불꽃열정` 3연전(15:19·15:29·15:45)은 개막 전 연습이다 —
   행사 `starts_at` 과 VOD1 오프닝이 그 경계를 준다.

## 목록 보관 기간 — 한국 날짜 기준 최근 30일 (2026-09-25·26 실측)

넥슨 `/fconline/v1/user/match` 목록은 **한국 날짜 기준 최근 30일** 경기만 준다. 건수 제한이 아니다
(계정마다 108~177건으로 제각각이었고, 모두 목록이 자연히 끝났다).

| 조회 시각 | 임유진 가장 옛 경기(종료) | 서도일 가장 옛 경기들(종료) |
|---|---|---|
| 09-25 01:25 | 08-26 00:08 | 08-26 05:09 · 05:26 · 08-27 05:39 |
| 09-26 01:38 | 08-27 01:42 | 08-27 05:39 |

- 하루 사이 8/26 종료 경기만 빠지고 8/27 01:42 는 남았다 — 「조회 시각 −30일」이 아니라 **날짜 단위**다.
- 0시 정각에 빠지는지는 못 봤다(자정 전후 10분 간격 확인이 도중에 멈췄다).
- **귀결:** 30일이 지나면 넥슨 API 로는 영영 못 받는다. 뿌챔스(8/25)의 10·14·22·24경기는 새 계정을
  한 페이지(100건)만 받은 뒤 한도(429)에 걸린 사이 날짜가 넘어가 사라졌다. 그래서 수집은
  「최근 N건」이 아니라 계정 커서(`fco_account.list_synced_until`)까지 목록을 넘긴다(0041, sync.ts).
- 호출 한도는 앱당 **하루 1,000회**(`5:1,1000:86400`)다. 저장 경기 1,819건 중 1,085건이 공식경기(50·60,
  랜덤 매칭)였고 그중 스트리머끼리는 1건이었다 — 한도의 대부분이 여기에 쓰인다.
