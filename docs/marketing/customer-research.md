## 핵심 결론 (한 줄씩)

1. **CK 전적은 커뮤니티의 "근거 자료"다** — 말싸움·팀 짜기·스트리머 평가에 전적 사이트 숫자를 직접 인용한다. 수요는 확실하다. (High)
2. **세트(판) 단위 기록을 원하는 목소리가 있다** — sooplol 은 거절했지만 **숲로그가 이미 제공**한다(아이템·룬까지). 수요는 있으나 빈칸은 아니다. (Medium)
3. **기록의 빠짐·틀림이 가장 큰 불만** — 사람 손 제보에 기대는 구조라 누락·오기가 잦고, 스트리머 본인까지 고치러 온다. 정확도·자동 수집이 곧 경쟁력이다. (High)
4. **스트리머가 직접 쓴다** — CK 멤버를 짤 때 최근 전적·승률을 본다. 스트리머는 "퍼뜨리는 사람"이기 전에 **사용자**다. (Medium)

## 테마 (빈도 × 강도 순)

### 테마 1: 빠진 기록·틀린 기록 — "누락", "수정 부탁드려요"
**요약:** 경쟁사 기록은 제보로 채워진다. 빠진 CK를 사용자가 라인업까지 받아 적어 제보하고, 틀린 참가자·포지션·승패를 고쳐 달라는 글이 계속 온다. 한 건(천상계CK 참가자 오기)에 같은 정정이 **5번** 접수됐다.
**빈도:** 피드백 약 35건 중 누락 제보 약 15건, 오류 정정 약 12건 · 디시에도 "CK 사이트가 뒤늦게 나와서 누락된 전적이 꽤 있음"
**강도:** 높음 — 같은 정정 반복, **당사자(스트리머)가 직접 정정**("9월 15일자 해당 ck에 참여한적이 없습니다")
**대표 원문:**

- "미드랑 정글이 각 팀 서로 포지션이 뒤바뀐 상태네요 수정 부탁드립니다!" — sooplol 피드백, 2026-10-09
- "장지수팀이 이겼는데 효딤님 승처리가 되어있습니다 … 패인데 승으로 처리되있네요" — sooplol 피드백, 2026-09-08
- "9월 8일 영재CK 누락" / "8월 12일에 열린 천상계ck 누락이라 제보드립니다" — sooplol 피드백
- "CK 사이트가 뒤늦게 나와서 누락된 전적이 꽤 있음" — 디시 숲 롤대남
**시사점:** 우리는 VOD를 판독기로 훑고 사람이 검수한다 → **누락이 적고 근거가 있다**는 점이 이 불만에 대한 직접적인 답이다. 다만 우리도 틀릴 수 있으니 **오류 제보 창구는 출시 첫날부터** 있어야 한다(계획된 오류·등록 요청 페이지).

### 테마 2: 세트(판) 단위로 보고 싶다 — "본판", "범찾판", "스코어"
**요약:** 사이트들이 CK를 "본판 결과" 한 줄로만 올려서, 본판 뒤의 판들(범인 찾기 판 등)까지 세트별로 보고 싶다는 요청. sooplol 은 "ck 정보에서 스코어도 같이 볼 수 있을까요?" 요청을 **반려**했고, "세트별 교체 인원이 있으면 전적이 등록되지 않는다"고 적어 둔다.
**빈도:** 직접 요청 2건(디시 1, sooplol 1) + 경쟁사 제한 문구 1 + 세트 기록 사이트를 반기는 글 1 — 표본 작음
**강도:** 중간 — "범인" 찾기(어느 판에서 누가 못했나)와 연승·연패 궁금증으로 이어진다
**대표 원문:**

- "가능하다면 ck 정보에서 스코어도 같이 볼수있을까요?" — sooplol 피드백, 2026-10-09 (**반려**)
- "오늘 클ck 전적이랑 범인 알려주실분" — 디시 숲 롤대남, 2026-10-08
- "여기 롤CK 전적사이트도 괜찮아보임 … 날짜 / 멤버 / 사용한 챔프 / 챔피언 통계 / 상대전적 / 최근20경기 다 보여줌" — 디시 숲게임, 2026-10-08 (첨부 화면: 세트별 챔피언·KDA·시리즈 스코어·결정전 — **sooplol 이 아닌 다른 사이트, 이름 미확인**)

### 테마 4: 스트리머가 직접 쓴다 — 팀 짜기·기록 관리
**요약:** CK를 여는 스트리머가 최근 전적·승률을 보며 멤버를 구성하고, 하위권 스트리머는 "전적 쌓기"를 의식한다. 스트리머 본인이 기록 정정을 요청한다.
**빈도:** 디시 3건 + 피드백 당사자 정정 1건
**대표 원문:**
- "상어녀는 사이트까지 다 보면서 CK 멤버 짜고있네? … 최근전적 최근승률 하나하나 다 보면서 멤버 구성하는데? … 롤CK는 저렇게 짜는게 맞긴해" — 디시, 2026-09-05

- "ck하는데 전적 사이트에서 룬 보고 찍음" — 디시
**시사점:** 스트리머용 기능(밸런스 맞추기·팀 구성 보조, 내 기록 정정 요청)이 **스트리머를 사용자로 만드는 입구**다. 덥덥미의 "내전 매칭 도우미"와 같은 방향. 실시간 캠공유도 같은 줄.

### 테마 5: 기록 범위 — CK만? 대회? 번외판?
**요약:** "ck 대결이를 받은건 아닌데 랜드도 기록되나여?"(정식 CK가 아닌 판도 기록되나), 개인 주최 리그(나락계리그) 등록 요청, CK 일정 예고 요청("CK예정일정이 있었으면 좋겠음" — sooplol 이 반영).
**시사점:** 무엇을 CK로 칠지 **기준을 공개**해야 한다(sooplol 은 about 에 집계 기준을 둔다). 일정 예고는 재방문 장치로 수요가 확인됨(편성표와 연결 가능).
