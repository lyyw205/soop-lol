# 멸망전 세트 검증 장부

멸망전 한정의 일회성 검증 기록이다. 시즌마다 아래 4단계를 한 번 돌리고, 결과와 남은 조사거리를 여기에 쌓는다.
나중에 한꺼번에 조사하고 체크할 수 있게 **시즌별로** 모은다. 주기적으로 수집하지 않는다(ck-research 스킬과 무관).

## 4단계

1. **나무위키 → DB:** 세트 결과표에서 스트리머·라인·챔피언·K/D/A·진영·승자를 채운다(`seed/lineups/<event>.json` → 시드 → DB).
   선수 K/D/A 합이 팀 합계와 맞는 팀만 K/D/A 를 넣는다. 스트리머로 등록되지 않은 선수는 `observed_name` 으로 넣는다.
2. **DB 합계 ↔ 나무위키 팀 합계:** 팀별 K/D/A 합계를 비교한다.
3. **VOD RESULTS 화면 판독:** 공식 중계의 세트별 RESULTS 화면(골드·팀 K/D/A·경기 시간·세트 스코어·딜량)을 읽는다.
   판독하는 쪽은 나무위키 값을 보지 않는다. 그래야 독립 검증이 된다.
4. **세 곳 일치 → 확정:** 팀 K/D/A·경기 시간·승패가 셋 다 맞는 세트만 RESULTS 프레임을 증거 프레임(`kind='result'`)으로 붙인다.

체크 칸: `[ ]` 아직 조사 안 함 · `[x]` 조사·처리 끝.
