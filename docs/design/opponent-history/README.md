# 개인 기록 · 상대 전적 탭

2026-09-22 반영. `/s/danuri?tab=opponents`에서 확인한다.

- 날짜별 그룹 없이, 선택한 기간 전체를 상대별 한 행으로 합산한다. 매치 히스토리와 같은 접이식 행에서 승/무/패, 승률, 경기·세트 수를 보여주고 펼치면 날짜가 포함된 맞대결 이력을 보여준다.
- 목록 바로 위 한 줄은 적용된 기간·카테고리·상대/맞라인 요약, 상대 수, 우측 정렬 선택으로 구성한다. 별도의 중복 기간 설명은 제거했다.
- 집계 전에 같은 팀 기록을 제외한다. 같은 팀으로만 만난 스트리머도 목록에 나오지 않는다.
- 전체 / 최근 6개월 / 3개월 / 1개월 / 1주 알약과 `YYYY-MM-DD` 시작일·종료일 입력을 제공한다.
- 상단 필터는 `상대/맞라인 | 기간 알약 | 시작일–종료일·적용` 순서로 한 줄에 둔다. 컨트롤 높이는 모두 32px이며, 좁은 화면에서는 필터 영역만 가로 스크롤한다.
- 목록 제목 우측에서 경기 많은 순 / 최신순 / 승률 높은순 / 승률 낮은순 정렬을 선택한다. 정렬 변경 시 다른 필터는 유지한다.
- 날짜 범위는 한국 날짜 양 끝을 포함한다. 최근 1주는 오늘 포함 7일이다. 다전제는 시작일로 기간을 판정하고 전체 세트를 유지한다. 맞라인은 해당 다전제의 모든 세트가 맞라인인 경우만 집계한다.
- 필터는 URL에 저장하며 카테고리 변경 시 유지된다. 연도 선택은 직접 기간 선택을 대체한다. 상대전적 상세로 이동할 때 기간·카테고리·맞라인 조건이 이어진다.

## 확인

- 기간·집계 단위 테스트 11개 통과: 같은 팀 제외, 중복 세트, 무승부, 혼합 포지션, 자정 경계, 한국 날짜, 윤년·월말, 잘못된 입력, 여러 날짜의 동일 상대를 한 행으로 합산.
- 웹 TypeScript 검사, 모듈 경계 검사, 프로덕션 빌드 통과. 빌드의 관리자 CK 프레임 경로 추적 경고 2건은 별도 기존 작업에 해당한다.
- 실제 DB를 읽는 브라우저 점검: 기간 알약 4개, 직접 입력, 역전된 날짜 검증, 맞라인 전환, 정렬·카테고리, 빈 결과, 전체 초기화, 잘못된 URL 날짜, 상세 페이지 날짜·맞라인 전달, 기존 매치 히스토리 회귀 확인.
- 360px 모바일 가로 넘침 없음. 브라우저 런타임 오류 없음. 현재 다누리 데이터의 맞라인 결과는 0명이며, 양수 집계와 혼합 포지션 제외는 별도 단위 테스트로 확인했다.
- 최신 캡처: `summary-desktop.png`, `summary-mobile.png`. 1440px·1280px·360px에서 상단 필터 한 줄 및 32px 높이, 정렬 선택의 우측 정렬과 페이지 가로 넘침 없음을 확인했다.

## 로컬 서버 연결 메모

이번 검토에서 기존 Supabase 트랜잭션 풀러(:6543)는 페이지 DB 조회가 응답하지 않는 현상이 재현됐다. 동일 DB의 세션 풀러(:5432)로 실행 환경의 URL 포트만 바꾼 로컬 서버는 정상 응답했다. 검토 서버는 `http://localhost:3001`에서 실행 중이며 `.env.local`이나 DB 연결 코드에는 우회 변경을 남기지 않았다. 재시작 후 같은 현상이 발생하면 로컬 연결의 세션 풀러 사용 여부를 확인한다. 모든 실제 DB 확인은 읽기만 수행했다.
