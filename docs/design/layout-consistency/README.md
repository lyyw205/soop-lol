# 개인 기록 · 상대전적 공통 레이아웃

검토 서버: http://localhost:3001

두 화면 모두 `검색 → 카테고리·기간 필터 → 요약 카드 → 섹션 메뉴 → 경기 기록` 순서로 구성한다. 데스크톱에서는 같은 너비의 오른쪽 열에 스트리머 정보, 최근 수상 경력, 통산 모스트 챔피언을 표시한다. 모바일에서는 같은 순서로 한 열에 배치한다.

- 공통 컴포넌트: `RecordLayout`, `RecordFilters`, `RecordSidebar`.
- 개인 요약도 챔피언 배경과 오버레이, 원형 프로필, 하단 기록 링크를 사용한다.
- 양쪽 요약 카드의 최소 높이와 검색 영역 높이를 맞춘다. 긴 콘텐츠는 잘리지 않고 늘어난다.
- 상대전적의 추천 매치업과 전적 흐름은 경기 목록 아래로 이동했다.
- 개인 기록도 주요 메뉴의 ‘전적 검색’ 아래에 속한다.
- 카테고리·연도 및 상대 선택을 유지하는 기존 이동 동작을 보존했다.

검증: 웹·모듈 TypeScript 검사, 모듈 경계 검사, 프로덕션 빌드 통과. 빌드에는 기존 관리자 프레임 라우트의 동적 파일 경로 추적 경고가 남아 있다.

브라우저에서 1440 / 768 / 360px의 검색·필터·요약·섹션 메뉴·첫 목록의 시작 위치와 폭이 양쪽 화면에서 일치함을 확인했다. 모바일 가로 넘침 없음. 카테고리를 유지한 양방향 이동, 경기 펼치기, 개인 기록의 대회·상대·챔피언·경기 탭, 기록 없는 연도와 필터 해제를 확인했다. 런타임 오류 없음.

각 화면의 전체 캡처는 `personal-{width}.png`, `versus-{width}.png`에 있다. 실제 데이터 기반이며 데이터 수집에 따라 내용은 달라질 수 있다.

## 자주 만난 매치업 축소

자주 만난 매치업은 오른쪽 정보 열의 모스트 챔피언 아래로 이동했다. 각 링크는 프로필·세트 스코어·프로필 순서의 58px 높이 행이다. 챔피언 배경과 카드 장식을 제거하고 얇은 행 구분선, 고정된 스코어 열로 테이블형 리스트를 구성했다. 사진과 이름은 가로로 묶어 양쪽이 마주 보게 배치하고, 우세한 쪽의 숫자만 주황색으로 강조한다. 최종 데스크톱 패널 캡처는 `matchup-list-refined.png`이다. 본문 아래의 큰 추천 카드는 제거했다. 모바일에서도 같은 간결한 행을 사용한다.

웹·모듈 타입 검사와 모듈 경계 검사 통과. 브라우저에서 우측 배치, 80px 이하 행 높이, 매치업 이동, 현재 쌍 제외, 모바일 가로 넘침 없음, 잘못된 검색어의 빈 상태를 확인했다. 캡처: `compact-matchups-desktop.png`, `compact-matchups-mobile.png`.
