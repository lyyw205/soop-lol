## 현재 화면에서 바꾸려는 점

홈의 긴 서비스 소개보다 두 스트리머 선택을 앞에 둔다. 결과는 이름 → 경기 승수 → 승률 → 경기 기록 순서로 읽게 한다. 이름을 누르면 프로필로, 프로필의 상대 목록을 누르면 다시 상대전적으로 이어진다. 수상 경력은 프로필의 주요 콘텐츠로 취급한다.

카드 수를 늘려 화면을 채우기보다 구분선·여백·글자 크기로 위계를 만든다. 색상은 한 가지 강조색과 중립색을 기본으로 한다. 실제 인물 사진을 확정하기 전까지 이름 기반 아바타를 사용한다.

## 후보 비교

| 방향 | 적용 방식 | 장점 | 다음 검토점 |
| --- | --- | --- | --- |
| A · 밝은 기록실 | 따뜻한 흰색, 녹색 포인트, 오른쪽 관련 기록 | 상대전적과 프로필의 균형, 확장하기 쉬운 기본 구조 | 작은 보조 텍스트의 크기, 여백을 더 줄일지 |
| B · 스포츠 지면 | 종이색, 세리프 숫자, 왼쪽 보조 정보, 수평 구분선 | 스코어의 존재감과 고유한 인상 | 한국어 본문과 숫자의 조화, 정보량이 늘어날 때 밀도 |
| C · 스코어보드 | 차콜, 세이지 포인트, 고정 메뉴, 압축된 목록 | 반복 탐색과 어두운 환경 | 모바일 메뉴 확장, 사이드바가 필요한 서비스 규모인지 |

1차 추천은 A. B의 숫자 크기·서체를 부분적으로 조합할 수 있다. C는 색만 바꾼 A가 아니라 탐색 메뉴와 결과 영역의 배치도 달리한 대안이다.

이 시안들은 레퍼런스 사이트의 복제본이 아니다. 해당 사례의 일부 원칙을 프로젝트 목적에 맞게 재해석했다. 특히 Onefootball의 현재 서비스 화면을 조사했다는 의미는 아니다. 원문 링크와 캡처를 함께 보면서 채택할 요소를 고른다.

## 확인 가능한 동작

- A/B/C 전환, 390px 모바일 미리보기, 레퍼런스 메모 펼치기.
- 스트리머 선택·순서 변경, 같은 인물 선택 방지.
- 상대 팀 / 같은 팀 / 맞라인, 2026년 필터, 2025년 빈 결과.
- 경기별 상세 펼치기, 스트리머 목록 → 프로필 → 상대전적 이동.
- 수상 경력 중심 프로필, 후속 모듈 배치를 위한 리더보드 샘플.

전체 기간과 2026년의 집계는 레이아웃 검토용 고정값이다. 경기 목록은 예시 네 행만 보여주므로 전체 집계의 근거 데이터로 사용할 수 없다. 검색은 1차 시안에서 여섯 명의 선택 메뉴로 표현했고, 실제 적용 때 기존 자동완성 검색과 모듈 등록부를 연결한다. 프로덕션 홈·공개 화면·DB는 변경하지 않았다.

## 검증

Chromium에서 세 방향의 데스크톱(1440px)·모바일(390px) 상대전적 및 프로필 화면을 캡처했다. 세 방향 모두 모바일 가로 넘침 없음. 필터·빈 상태·중복 선택 방지·경기 펼치기·참가자 변경을 확인했고 JavaScript 오류는 없었다. 시각 검토 후 작은 프로필 링크와 스코어 대비를 조정했다.
