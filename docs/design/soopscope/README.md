# SoopScope 디자인 시스템 · 전적검색 비교 버전

조사/적용: 2026-10-15. 원본: https://soopscope.com


## 현재 적용: 기본 디자인 + 캠공유 박스 색상

비교 토글과 SoopScope/캠공유 전체 팔레트 전환을 제거했다. 기본 디자인을 사용하며 전적검색·개인기록·상대전적의 중립 박스 배경은 `#141b25`, 테두리는 `#303a47`, 상세 팀 박스는 `#1b2532`로 적용한다. 공통 색상은 `globals.css`의 `--surface-panel`, `--surface-panel-soft`, `--surface-border`로 관리한다. `arena.css`, `fc.css` 및 LOL·FC 대회 모듈에서 기존 기본 박스/테두리 색상을 쓰던 곳도 같은 토큰을 사용한다. 전적 상세 보완은 `record-surfaces.css`에 있다.

페이지 배경·글자·버튼·강조색·레이아웃은 기존 스타일을 사용한다. 챔피언 이미지와 오버레이, 승패 의미색도 유지한다. 아래 디자인 분석과 미리보기는 비교 실험의 이력이다.

## 결과와 조사 범위

공개 메뉴·푸터·홈 내부 링크를 따라 **25개 경로/화면을 캡처**했다. 탐색뿐 아니라 홈, 랭킹, 라이브, 두 종류의 미션과 상세, 월간 리캡, 공지, 게임, 도움말, 폼과 문서를 함께 비교했다. 로그인으로 보호된 화면은 접근 안내까지만 관측했다. 모든 스트리머/방송 ID의 페이지를 전수 방문하거나 회원 전용 화면까지 분석한 것은 아니다.

초기 기본 HTTP 및 headless User-Agent에서는 403이 반환되었다. 일반 Chrome User-Agent를 지정한 같은 URL 요청에서는 200과 정상 렌더링을 확인했다. User-Agent에 따른 필터링은 재현했지만 서버 정책/차단 제품은 알 수 없다. 검색 도구의 과거 캐시 대신 이후 실제 브라우저의 DOM, computed style, CSS custom property, 화면 캡처를 기준으로 이 문서를 작성했다.

- [관측 토큰 원본](observed-tokens.json): 실제 CSS 변수와 콘텐츠 컨테이너 치수.
- [페이지별 측정값](page-measurements.json): URL, 접근 상태, 요소별 글꼴·크기·색상·배경·경계·반경·간격.
- [원본 화면 캡처](reference/): 데스크톱 1440px, 탐색 모바일 375px, 검색 결과 없음 상태.
- 각 화면의 데이터는 조사 당시 값이다. 인원·순위·후원액을 디자인 상수로 사용하지 않는다.

## 1. 사이트를 관통하는 원칙

**검정 배경과 명도 차로 구역을 나누고, 큰 제목 아래에서 탐색 도구와 데이터를 바로 보여준다.** 탐색 카드에는 면을, 순위/미션 목록에는 얇은 구분선을 사용한다. 모든 것을 큰 테두리 패널에 넣지 않는다.

**주요 동작과 선택은 흰색이 기본이다.** 브랜드의 청록색이 버튼 전체로 확장되지는 않는다. 상단 메뉴에는 보라 밑줄, 수치에는 금색, 팀에는 파랑/주황, 생방송에는 빨강처럼 의미가 있는 곳에 색을 제한한다.

**정보 계층을 타이포그래피로 만든다.** 제목은 큰 글자와 좁은 자간, 이름은 16px bold, 보조 데이터는 작은 회색, 지표는 굵은 숫자로 구별한다. 서체는 Pretendard Variable이며 우리 서비스에 이미 같은 폰트가 있어 추가 다운로드가 필요 없다.

### 크기·간격·반경

- 메인 max-width 1280px. 1440px 뷰포트에서 바깥 80px + 내부 24px = 콘텐츠 시작 x=104px, 실사용 폭 1232px.
- 모바일 내부 여백 16px. 원본 탐색 상단 36px, 큰 화면 56px, 하단 80/112px.
- 헤더 내부: 1280px, 가로 24px(모바일 16px), 세로 10px. sticky + 반투명 `#111111/95` + backdrop blur.
- 탐색 입력: 데스크톱 60px, 모바일 56px, 반경 16px. 검색 아이콘 왼쪽과 초기화 영역을 확보.
- 인물 카드: 반경 16px, padding 20px(모바일 16px), 아바타 52px, 이름 옆 간격 14px.
- 보조 버튼/필터: 반경 9~12px. 배지는 5px.
- 정렬 segmented control: 어두운 바탕 안에서 선택 버튼만 더 밝은 표면.
- 효과는 표면색 변화 중심. 일반 카드에 큰 그림자나 글로우를 추가하지 않음.

## 4. 컴포넌트와 상태

### 전역 메뉴

브랜드 + 기능 메뉴 + 전역 검색 + 로그인을 한 줄에 둔다. 활성 메뉴는 어두운 둥근 바탕과 짧은 보라색 밑줄로 구별한다. 모바일은 로고/검색/메뉴 버튼으로 축약한다. 비교 버전에서는 기존 SOOP SEEK의 게임 전환 및 메뉴를 유지하며, 모바일의 가로 메뉴와 스크롤을 유지했다. 원본의 모바일 메뉴 구조까지 새로 만들지는 않았다.

### 탭과 정렬은 구별

페이지의 주요 콘텐츠 전환은 흰색 2px 밑줄이다. 기간/정렬 같은 보조 선택은 둥근 segmented control이다. 비교 버전의 개인 기록/상대전적은 1차 탭, 디자인 비교는 보조 segmented control로 적용했다.

### 카드와 표

인물 탐색은 어두운 면, 52px 원형 아바타, 이름, ID, 작은 배지, 아래 구분선 뒤의 지표다. 비교 버전은 하단을 개인 기록 링크로 치환했다. 대상별 지표가 없는 상태에서 원본의 후원액을 임의 승률 등으로 바꾸지 않았다. 동일 slug의 FC 복수 계정은 탐색 카드에서 한 명으로 합친다.

### 입력·로딩·빈 상태

검색창은 넓고 대비가 낮은 표면을 사용하며, 포커스에서 경계를 강화한다. 원본은 탐색 로딩 중 카드 골격을 보여주고 결과 없음 상태에서는 검색어와 재검색 방법을 보여준다. 비교 버전은 기존 자동완성·오류·pending 동작을 재사용한다. 이미 서버에서 받은 디렉터리를 표시하므로 장식용 skeleton이나 가짜 로딩은 넣지 않았다.

### 접근성 조정

원본의 4차 회색과 작은 글씨를 그대로 따르지 않고, 필수 안내를 더 밝게 했다. 비교 토글 최소 높이는 44px, 검색 입력 모바일 글자는 16px, 키보드 포커스는 명시적인 outline이다. 기존 검색 탭의 방향키/Home/End와 자동완성의 방향키/Enter 동작을 유지한다. 카드 색상 전환은 reduced-motion에서 제거한다.

## 5. 구현 및 비교 방법

- LOL: http://localhost:3000/lol
- FC: http://localhost:3000/fc/search
- 상단 `기존 / SoopScope` 버튼으로 전환한다. 선택은 브라우저 localStorage에 저장되며 두 게임에서 공유한다. 첫 방문 기본값은 기존이다.
- 같은 검색 컴포넌트를 유지하여 전환 시 인물 입력과 검색 방식이 초기화되지 않는다.
- 새 화면의 스트리머 카드에는 실제 공개 검색 옵션을 사용한다. 목록 검색과 12명씩 더 보기를 제공한다.
- 비교 범위는 LOL·FC 검색 진입 화면과 개인전적·상대전적 결과 화면이다. 관리자와 전적 외 화면에는 적용되지 않는다.

| 파일 | 책임 |
| --- | --- |
| `packages/ui/record-design-preview.tsx` | 토글, 접근 가능한 선택 상태, 디자인 context, 선택 저장 |
| `packages/ui/record-discovery.tsx` | 실제 인물 목록, 필터, 더 보기, 개인 기록 링크 |
| `packages/ui/record-search.tsx` | 기존 검색 동작 유지, 새 디자인에서 탐색 목록 추가 |
| `apps/web/app/record-design-preview.css` | 원본 관측 토큰과 범위를 제한한 스타일 |
| `apps/web/app/lol/page.tsx` | LOL 비교 호스트 |
| `apps/web/app/fc/search/page.tsx` | FC 비교 호스트 |
| `apps/web/app/layout.tsx` | 비교 CSS 로드 |

스타일은 `[data-record-design=scope]`가 존재할 때만 적용한다. body 배경/공통 헤더도 이 조건으로 묶여 있어 전적 화면을 벗어나면 원복된다. React 자식 트리를 두 벌로 교체하지 않는다.

## 6. 검증

- `npx tsc -p apps/web --noEmit`: 통과.
- `node scripts/verify-modules.ts`: 모듈 경계·공용 UI 의존성·사이트 공통 스타일 규칙 통과. 처음 발견된 font-size 리터럴은 의미별 토큰으로 정리했다.
- Playwright로 LOL/FC 각각 기존→SoopScope→기존 전환 중 검색 입력 유지, 저장 선택의 새로고침 복원 확인.
- 목록 검색 결과 없음, 초기 12명→더 보기 24명, 키보드 자동완성 선택 확인.
- 개인 기록 탭 전환 및 제출 후 실제 `/s/…` 프로필 이동, 비교 스타일 범위 해제 확인.
- 1440×1000 / 768×1024 / 375×812 / 812×375에서 검사. 모바일/가로 화면의 문서 가로 넘침 없음. reduced-motion 환경에서도 검사.
- 브라우저 pageerror 없음. `git diff --check` 통과.
- 초기 확인에서는 새로고침 후 hydration 이전 값을 읽는 검증 타이밍 문제가 있어, 저장된 디자인이 복원될 때까지 기다리도록 검증을 보완했다. 812px에서 발견한 메뉴 넘침은 메뉴 영역의 스크롤과 최소 폭을 수정해 해결했다.

## 7. 개인전적·상대전적 확장

사용자 추가 요청에 따라 LOL·FC의 개인전적과 상대전적 결과에 같은 비교 토글을 적용했다.

- 공통 `RecordLayout`이 결과 화면 토글을 제공한다. 검색 진입의 기존 토글 아래에서는 중복 렌더링하지 않는다.
- 저장한 디자인이 검색 → 개인전적 → 상대전적으로 이어진다. 프로필 탭, 정렬, 기간, 순서 바꾸기를 이동해도 선택이 유지된다.
- 결과 화면에는 인물 탐색 목록을 추가하지 않는다. 기존 프로필·일정·커뮤니티 사이드바는 유지한다.
- 프로필 요약과 맞대결 카드는 장식 배경 대신 회색 표면과 숫자 위계를 사용한다. 기간/분류는 둥근 컨트롤, 콘텐츠 탭은 흰 밑줄로 통일했다.
- 매치 목록·펼친 팀 상세·챔피언 표·FC 지표/사용 선수/스쿼드 표에도 중립 표면을 적용한다. 승패·팀 색과 실제 수치는 유지한다.
- 모바일 요약은 경기/승무패/승률의 너비를 조정했다. FC 스쿼드 표의 숨김 라벨이 문서 밖으로 빠지는 문제는 스크롤 컨테이너에 위치 기준을 지정해 해결했다.

확장 검증: 타입 검사, 모듈/스타일 경계 검사, LOL·FC 네 화면의 토글 전후 입력/수치/펼침 상태, 새로고침, 1440/768/375/812px 레이아웃 통과. LOL 개인 상대/대회/챔피언 탭, FC 개인 상대/대회/스쿼드 탭, FC 상대 경기지표/사용선수 탭, LOL 관계 선택·순서 교환, 검색에서 프로필 이동, 전적 외 경로에서 스타일 해제도 확인했다.
