# 개인 프로필 카드 시안

미리보기: http://localhost:3001/design-lab/profile-card.html

기존 개인 기록 페이지의 중앙 정렬 프로필을 좌측 이미지 / 우측 정보 구조로 비교하는 정적 시안입니다. 선택한 A안은 실제 [개인 기록 페이지](http://localhost:3001/s/danuri)에 반영했습니다. 실제 방송 링크에는 플랫폼 대신 공개 스트리머명을 표시합니다.

- **A / 프로필 통합형**: 큰 프로필 이미지 옆에 이름과 전적을 배치하고, 하단에 방송 채널·모스트 챔피언·수상 경력을 통합합니다.
- **B / 전적 우선형**: 작은 프로필 이미지, 이름, 전적을 한 줄로 묶어 카드 높이를 줄입니다. 부가 정보는 A와 동일합니다.
- 방송 채널은 가로 한 행, 그 아래 게임 계정은 계정당 한 행으로 표시합니다. 계정 이름·태그·티어를 함께 표시하고 프로필 이름 아래의 계정 중복 표시는 제거했습니다. 가상 예시는 계정 3개를 포함합니다.
- 모바일에서는 두 시안 모두 프로필 → 전적 → 방송·계정 → 챔피언 → 수상 경력 순서로 재배치합니다.

`apps/web/public/design-lab/profile-card.js`의 렌더 함수와 데이터 구조는 두 시안이 공유하며, 배치 차이는 CSS에서 관리합니다. 실제 페이지는 기존 공개 데이터 조회, 공용 `Avatar`, `AccountList` 및 `RankChip`을 사용합니다. 수상 경력과 챔피언 목록은 `packages/ui/record-profile-info.tsx`를 통해 상대전적 사이드바와 공유합니다.

데이터 선택에서 2026-09-22에 조회한 다누리의 공개 기록 스냅샷과 가상 스트리머 예시를 전환할 수 있습니다. 가상 예시는 수상 및 챔피언 정보가 많은 상태의 배치를 확인하기 위한 것이며 화면에 가상 데이터임을 표시합니다. 스냅샷은 실시간으로 갱신되지 않습니다. 챔피언 배경에는 기존 Thresh 이미지를 사용합니다.

브라우저 확인: A/B 전환, 데이터 전환, 실제 프로필/챔피언 이미지 로딩, 실제 기록 링크, 빈 수상 경력과 수상 2건 상태, 360–1440px 화면의 가로 넘침 및 전적 숫자 잘림 여부를 확인했습니다. JavaScript 구문 및 브라우저 런타임 오류 없음.

실제 페이지 적용 후 확인: 웹 TypeScript 검사 통과. 다누리 프로필에서 방송국명 링크, 계정 1행, 상대전적 탭과 매치 히스토리 이동을 확인했습니다. 샤코타임 프로필의 계정 2행과 빈 챔피언/수상 상태, 360–1280px의 가로 넘침, 상대전적 화면의 기존 사이드바도 확인했습니다. 현재 공개 DB에는 우승·준우승 기록이 없어 실제 데이터 검증은 빈 수상 상태 기준입니다.
