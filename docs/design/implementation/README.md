## 적용한 방향

엘로보드·SOOP e스포츠의 기록 탐색 구성과 Fixtured의 원형 인물 영역·큰 스코어·카드 하단 액션을 결합했다. 다크모드가 기본이며 카드에는 챔피언 원화와 어두운 오버레이를 사용한다. 장식 배경은 실제 경기에서 사용한 챔피언을 뜻하지 않는다.

홈은 등록부에서 상대전적 모듈을 불러온다. 선택기, 관계·연도 필터, 대표 전적, 다른 매치업, 경기 기록과 인물·수상 정보로 구성한다. 프로필은 같은 카드 디자인을 사용하고 기존 대회·상대·챔피언·경기 탭을 유지한다. 스트리머 목록에는 공개 프로필 사진을 넣었다. 사진이 없으면 공개 SOOP 채널 이미지를 사용하고, 이미지 요청이 실패하면 이름 두 글자를 표시한다.

메인 전적은 경기 승수, 보조 카드와 프로필 카드는 세트 승수이며 각 카드에 단위를 표시한다. 무승부를 별도로 표시하고, 같은 팀 모드는 공동 승패로 안내한다. 맞라인 경기 필터는 모든 세트가 맞라인인 경기를 포함한다. 비어 있는 데이터는 빈 상태로 표시한다. 기존 시안의 가상 전적과 수상 내역은 실제 페이지에 사용하지 않는다.

모듈은 공개 core 계약을 통해 인물·수상·챔피언 데이터를 읽는다. DB 스키마나 기록은 변경하지 않았다. 관리자 화면에는 공개 페이지의 스타일 범위를 적용하지 않는다.

## 로컬 실행

별도 검수 서버와 충돌하지 않도록 개발 캐시를 분리한다.

```sh
NEXT_DIST_DIR=.next/ui npm run dev -w @soop-lol/web -- --port 3001
```

`apps/web/.env.local`의 기존 연결 설정을 사용한다. 스크린샷 촬영 시 DB에는 스트리머 69명·수집 경기 1건이 있어 일부 프로필의 수상/챔피언 영역은 빈 상태였다.

## 검증

- 웹·모듈·코어 TypeScript 검사 통과.
- 기존 테스트 83개 통과, 모듈 경계 검사 통과.
- 프로덕션 빌드 통과. 기존 관리자 프레임 라우트의 파일 추적 범위 경고는 남아 있다.
- 실제 브라우저에서 데스크톱 1440px, 모바일 360px 확인. 가로 넘침·브라우저 런타임 오류 없음.
- 인물 순서 변경과 승수 반전, 같은 팀·맞라인·연도 필터, 경기 펼치기, 보조 카드 이동, 프로필의 각 탭, 검색 결과 없음, 동일 인물 선택, 잘못된 인물 주소, 리더보드 이동 확인.

주요 구현은 `apps/web/app/arena.css`, `packages/modules/versus/ui/`, `apps/web/components/`, 홈·목록·프로필 페이지다. 챔피언 원화 출처는 `apps/web/public/images/arena/sources.json`에 보존했다. 이전 정적 시안은 비교용으로 유지한다.
