# 국내 레퍼런스 추가 · 2차 비교

2026-09-22. Fixtured 레퍼런스를 1번 후보로 유지한다. 기존 `design-lab/index.html`과 1차 결과물은 수정하지 않았다. 레이아웃은 유지하되 게임·스트리머의 개성이 약하고 색·폰트·장식이 템플릿처럼 보인다는 피드백을 반영한다.

[비교 페이지](http://localhost:3101/design-lab/domestic.html)에서 1번 레퍼런스와 기존 시안 링크, 2·3번 인터랙티브 시안을 확인할 수 있다.

## 후보

| 번호 | 방향 | 이번에 비교할 요소 |
| --- | --- | --- |
| 1 | Fixtured — 보존 | 스포츠 이미지·경기 카드·큰 타이포그래피. 사용자가 유지한 레퍼런스이며 기존 시안을 최종 채택했다는 의미는 아님 |
| 2 | 국내 전적 서비스 | 포우·포로지지의 챔피언 아이콘과 정보 밀도. 밝은 배경, 한글 중심 제목, 프로필 사진, 파랑·빨강 전적 |
| 3 | 스트리머 경기장 | 엘로보드·SOOP e스포츠의 인물·대회 중심 구성에 게임 원화를 결합. 어두운 배경, 더 큰 인물 이미지, 금색 탐색 표시 |

두 추가 시안은 레퍼런스를 복제한 것이 아니라 같은 프로젝트 레이아웃에 적용한 해석이다. 색만이 아니라 표 간격·인물 크기·영역 구분·게임 이미지의 비중을 달리했다. 챔피언 장식은 아직 방향 비교용이며, 실제 적용에서는 해당 경기의 챔피언·대회 이미지로 연결해야 한다.

OP.GG와 YOUR.GG는 이 환경에서 403으로 접근되지 않았다. 확인하지 못한 현재 화면은 비교 근거로 쓰지 않았다. 원본 캡처는 이 폴더의 `ref-*.png`에 보존했다.

## UI 동작과 데이터

선택 메뉴, 중복 인물 방지, 관계·기간 필터, 빈 기록, 경기 펼치기, 프로필·수상 경력·목록 이동을 유지했다. 두 시안의 1440px 데스크톱 및 390px 모바일을 확인했고 모바일 가로 넘침과 JavaScript 오류가 없었다.

인물 이미지는 SOOP 공개 프로필, 챔피언 아이콘·배경은 Riot Data Dragon 원본을 사용한다. 출처는 `apps/web/public/design-lab/assets/sources.json`. 실제 공개 이미지와 별개로 **전적·수상·챔피언 조합은 모두 가상 예시**이며 실데이터에 연결되지 않는다. 추가 라이브러리는 설치하지 않았다.
