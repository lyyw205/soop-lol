# 개인 기록 기본 화면: 매치 히스토리

검토: http://localhost:3001 → 개인 기록 검색.

- ‘요약’ 탭을 제거하고 ‘매치 히스토리’를 기본 탭으로 바꿨다. 이어서 상대 전적·대회·챔피언을 배치했다.
- 특정 상대와의 조우가 아닌 본인의 공개 참가 기록을 기준으로 모든 경기를 최신순, 20경기씩 조회한다. 다전제는 한 행으로 묶는다.
- 상대전적과 같은 날짜·타임라인·접이식 경기 행을 사용한다. 행에는 경기명, 본인 팀, 스코어, 해당 경기의 상대 팀 또는 참가자 이름, 승무패, 세트 수를 표시한다.
- 펼치면 그 경기의 공개된 내 팀·상대 팀 스트리머를 보여준다. 여러 세트에 등장한 사람은 팀별로 한 번만 표시한다. 팀 구분은 매 세트의 본인 팀을 기준으로 계산한다.
- 상대와는 상대전적, 동료와는 같은 팀 전적으로 바로 이동한다. 카테고리·연도를 유지한다.
- 상대 스트리머가 공개되지 않은 경기에도 본인의 이력은 남긴다. 비공개 참가자 이름이나 계정 식별자는 표시하지 않는다.
- 기존 `?tab=summary` 링크는 기본 매치 히스토리로 표시한다. 위쪽 ‘경기별 기록 보기’도 현재 탭과 무관하게 히스토리로 연결한다.

검증: 웹·코어 타입 검사, 프로덕션 빌드 통과. 기존 관리자 프레임 라우트의 파일 추적 경고 2건은 남아 있다. 격리된 PGlite에서 다전제/페이지 경계, 세트 ID, 비공개 상대 처리 검증을 포함한 DB 검사를 통과했다. 현재 별도 CK 코드의 TypeScript parameter property 때문에 Node 실행에 `--experimental-transform-types`를 사용했다.

브라우저에서 기본 탭, 요약 제거, 참가자 펼치기, 상대/같은 팀 전적 연결, 필터 유지, 다른 탭에서 히스토리 복귀, 기존 요약 URL, 빈 연도, 모바일 가로 넘침 없음을 확인했다. 런타임 오류 없음. 실제 데이터 화면은 `desktop.png`, `mobile.png`에 보관했다.
