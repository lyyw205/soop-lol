# 대회 페이지 — 본페이지 적용 및 시안

## 본페이지 적용 (2026-09-25)

- [대회 목록](http://localhost:3000/lol/tournaments) · [Gen.G 상세](http://localhost:3000/lol/tournaments/meljang-2026-geng) · [참가 팀 표](http://localhost:3000/lol/tournaments/meljang-2026-geng?tab=teams)
- 기존 사이트 내비게이션에 **대회** 추가. 전체/멸망전/이벤트 매치 3분류, 최신 항목만 A 사진 스타일의 작은 카드(데스크톱 150px), 나머지는 B 스타일 표. 연도·대회/팀/스트리머 검색 지원.
- 목록은 개인 기록의 `RecordTimelineRow`를 사용한다. 연도는 해당 연도의 첫 대회와 같은 줄에 표시하고 첫 연결점만 강조한다. 분류 라벨은 제목 위에 두고 연도 사이에는 간격을 둔다.
- 상세는 A 히어로를 데스크톱 266px로 축소. 히어로 아래 4개 통계 스트립 삭제. 개요 유지, 일정/결과 탭 삭제. 해당 탭의 라운드/팀 필터·선택 경기 수·날짜 출처 차이 안내는 대진표에 통합. 경기별 세트 상세 유지.
- 참가 팀은 투표 순서의 팀당 1행·포지션별 열로 표시한다. 팀명 옆에는 진출 단계 라벨을 두고, 선수별 프로필·이름·등급·점수를 셀 안에서 분리해 보여준다. 주장·교체 이력도 유지한다.
- 개요는 좌측 경기 영역과 우측 정보 영역의 2컬럼이다. 좌측의 결승 카드 아래를 다시 2컬럼으로 나눠 챔피언스 5명과 한 카드에 묶은 우승팀 매치 히스토리를 보여주며, FINAL MVP는 해당 선수 행에 표시한다. 우측에는 참가 팀(우승·준우승 팀만 칩 표시), 대회 한눈에, 공식 채널·출처를 배치한다. 전체 14경기 대진은 별도 대진표 탭에 남긴다.
- 본페이지 경기/로스터는 `packages/core/lib/db/public-tournaments.ts`에서 **실제 core_public 뷰**만 읽는다. 정적 시안의 seed 스냅샷을 서비스 데이터로 사용하지 않는다. 추가 뷰는 `0038_public_tournament_match.sql`이며 기존 공개 경기의 숨김·LoL 분리를 계승한다.
- Gen.G 규칙·상금·투표·티어 등 출처 확인된 부가 정보는 `apps/web/lib/tournament-metadata.ts`에 보존했다. 목록과 상세는 `event.kind = 'tournament'`만 조회한다. CK·scrim·showmatch는 전체 탭에서도 제외한다. 이벤트 매치 탭은 tournament로 등록된 올스타·초청 대회 등을 구분하는 화면 분류다.
- 아래의 A/B 시안은 초기 비교용으로 유지했다. 초기 시안의 30개 항목과 실제 DB의 수집 범위는 다르다.

검증: `npm run build`, `npm run typecheck`, `npm run verify:db`, `npm run verify:modules`, `node --test packages/core/lib/metrics/tournament.test.ts`, `node scripts/verify-tournaments.mjs`.

2026-09-25 당시의 브라우저 검증 스크립트(verify-production.mjs)는 지금 화면(대진 공통 뼈대·참가 팀 카드·대회 안내 탭 없음)과 맞지 않아 2026-10-02 지웠다. `production/`의 스크린샷은 그때 기록이다. DB 질의 검증은 별도 PGlite에만 fixture를 만들며 숨김 경기/인물 제외, FC 분리, tournament 외 분류의 목록·상세 제외, KST 날짜를 검사한다.

두 안 모두 목록의 연도·분류·상태·대회/팀/스트리머 검색, 상세 탭, 라운드/팀별 경기 필터, 대진에서 경기 상세 열기, 세트 전환, 프로필 링크, 출처/공식 방송국 링크가 동작한다. URL로 상태를 공유하고 뒤로 가기·앞으로 가기를 사용할 수 있다. 모바일 대진표와 큰 통계 표는 해당 영역 안에서만 가로 스크롤된다.

공개 서비스 코드·DB를 변경하지 않은 독립적인 정적 시안이다. 데이터는 실시간 DB가 아닌 기존 seed의 공개 필드 스냅샷이다. 메인 내비게이션의 ‘대회’는 시안 내부에만 추가했다. 스크린샷보다 실제 링크에서 탐색하는 것을 권장한다.

## 포함한 화면과 정보

- **목록:** 멸망전, 이벤트 매치(CK·올스타), 초청 대회. 2014–2026년 30개 항목. 기본 2026년 6개.
- **개요:** 대표 결승 결과, 세트별 승자, 우승 로스터, 우승 경로, 최종 순위와 상금, 파이널 MVP, 대회 기본 정보.
- **일정·결과:** Gen.G 대회 14경기·36세트. 라운드·팀 필터. 일정 출처 불일치 안내.
- **대진표:** 승자조 7경기, 패자조 6경기, 최종 결승. 각 경기에서 세트 상세 진입.
- **참가 팀:** 본선 8팀, 포지션별 로스터, 주장, 투표 순위, 당시 대회 티어·포인트, 서포터 교체 이력.
- **기록실:** 확인된 출전·세트 승패, 부분 수집 범위를 명시한 평균 K/D/A, 챔피언 픽 수와 승패. 밴픽률로 잘못 표시하지 않는다.
- **세트 상세:** 해당 세트의 실제 출전 선수·챔피언·포지션·K/D/A·시간·승자·출처. 대회 등록 로스터를 세트 출전으로 간주하지 않는다.
- **대회 안내:** 운영, 스폰서, 본선 선발, 더블 엘리미네이션, BO3, 패치별 적용 단계, 본선/결승 경기장, 연계 행사, 상금·MVP·특전, 중계진, 공식 공지·티어 산정 안내·방송국 링크.

Gen.G 외의 항목도 자체 경기/로스터가 열린다. 데이터가 부분 수집된 대회는 ‘기록된 팀/세트’ 수로 표시한다. 이벤트 매치의 상금과 MVP를 지어내지 않는다. CK를 ‘이벤트 매치’에 넣은 것은 탐색 UI의 제안이며 DB의 `event.kind`를 재분류한 것이 아니다.

자료 간 차이는 숨기지 않았다:

1. 패자조 1R 명 수–저로듀스lol: 미러 안내 일정은 7/22, 기존 시드는 7/23. 경기 목록은 기존 시드를 유지하고 확인 필요를 표시한다.
2. 결승 3세트 K/D/A: 기존 판독에서 원문 합계 불일치로 제외된 값이다. `미확인`으로 표시하며 평균에서도 제외한다.
3. 본선 로스터 40명과 실제 출전 인원은 교체 선수 때문에 다를 수 있다. 서로 다른 지표로 표시한다.
4. 3위 이하 순위는 더블 엘리미네이션의 탈락 단계로 계산한 순위다. 공동 순위를 임의로 나누지 않는다.
5. 시드의 시각 정밀도를 확인하지 못해 일정에는 날짜만 표시한다. 세트 순서를 모르면 ‘수집 경기’로 표시한다.
6. 대표 사진은 SOOP 제공 실제 우승 사진이다. 챔피언 배경 원화는 장식이며 경기 픽의 근거가 아니다. 출처는 `assets/sources.json`에 기록했다.

## 실행과 검증

기존 개발 서버(`npm run dev`, 현재 포트 3000)에서 링크를 연다. 서버 포트가 다르면 위 링크의 포트만 바꾼다. 디자인 파일은 `apps/web/public/design-lab/tournaments/`에 있다.

```bash
# 로컬 시드로 공개 필드만 다시 내보내기. DB 읽기/쓰기 없음.
node docs/design/tournaments/build-data.mjs

# Playwright 검증과 스크린샷 재생성
node docs/design/tournaments/verify.mjs
# 다른 포트
TOURNAMENT_PREVIEW_URL=http://localhost:3001/design-lab/tournaments/index.html node docs/design/tournaments/verify.mjs
```

1440px, 390px, 360px에서 두 시안의 목록 및 상세 탭 6개를 검사했다. 가로 넘침·브라우저 JS 오류 없음. 연도/분류/이름/상태 검색, 검색 결과 없음과 초기화, 세트별 승자와 선수 10명, 결승 3세트 미확인 K/D/A 10명, 대진 14경기, 참가 팀 8개, 팀별 경기 필터, A/B 전환 후 상태 유지, 뒤로 가기와 이벤트 매치 진입을 확인했다. 결과는 `verification.json`에 있다.
