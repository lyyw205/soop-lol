## 적용한 결정

전체 구성은 검색 → 상대전적 → 다른 매치업 → 경기 기록, 오른쪽은 인물 정보·수상 경력으로 유지했다. 프로필은 상대전적과 수상 경력을 연결한다.

Fixtured 카드에서 가져온 요소:

- 색으로 채운 한 장의 카드와 둥근 모서리.
- 반투명 원형 영역 안의 인물 이미지, 두 인물 사이의 얇은 구분선.
- 이미지 아래 이름, 그 아래 가운데에 놓인 큰 흰색 스코어.
- 상단의 경기 맥락, 하단의 기록으로 이어지는 동작.

메인 전적은 오렌지 카드, 보조 매치업은 파랑·초록·자주색 카드로 구성했다. 프로필의 ‘자주 만난 상대’도 동일한 카드 컴포넌트를 사용한다. 카드 색은 승패를 뜻하지 않는다.

첨부 이미지의 쿼터·경기 시간·중계 표시는 누적 전적 서비스에 맞게 기간·경기 수·기록 보기로 바꿨다. 닫기 버튼을 그대로 붙이는 대신 집계 설명 버튼을 제공한다. 같은 팀 모드는 인물별 승수가 아닌 공동 승패로 명시한다.

## 범위와 검증

시안의 검색·관계/기간 필터·순서 바꾸기·카드 이동·프로필·수상 경력·기록 펼치기·이름 검색·빈 상태가 동작한다. 같은 샘플 경기 목록에서 필터와 집계를 계산하며, 인물 순서를 바꿔도 전적은 반대로 대응한다.

1440px 데스크톱, 390px 미리보기, 360px 실제 뷰포트를 검사했다. 모바일 가로 넘침과 JavaScript 오류가 없었다. 중복 인물 선택 방지, 같은 팀 표기, 2024년 빈 결과, 기간별 집계와 전체 목록의 경기 수 일치, 경기 상세, 검색 결과 없음도 확인했다.

전적·수상·포지션·랭크는 디자인 확인용 샘플이다. 인물 이미지는 SOOP 공개 프로필이고, 게임 아이콘은 Riot Data Dragon 원본이다. 출처는 `apps/web/public/design-lab/assets/sources.json`. 사용자 첨부 원본도 `fixtured-card-reference.png`로 보존했다.

현재는 실서비스 적용 전 통합 시안이다. 기존 공개 페이지·DB·모듈 등록부는 수정하지 않았다. 1·2차 시안도 그대로 보존했다.

## 구현 파일

- `apps/web/public/design-lab/arena.html`: 검토 도구와 원본 카드 비교.
- `apps/web/public/design-lab/arena-preview.html`: 사용자 화면 진입점.

- `apps/web/public/design-lab/arena.js`: 공통 카드 렌더링과 샘플 탐색.

다음 실제 적용 시 카드와 화면 구성은 이 시안을 기준으로 옮기고, 데이터는 기존 core 계약과 모듈 등록부에 연결한다. 운영 집계 규칙을 이 샘플 계산으로 대체하지 않는다.
