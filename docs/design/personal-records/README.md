# 개인 기록 / 상대전적 검색

2026-09-22. 사용자 선택안 1: 검색 영역의 두 탭으로 개인 기록과 상대전적을 구분한다.

[로컬 페이지](http://localhost:3001) · [개인 기록 데스크톱](personal-desktop.png) · [개인 기록 모바일](personal-mobile.png)

## UX

- `개인 기록`은 스트리머 한 명을 골라 `/s/[slug]`의 실제 프로필로 이동한다.
- `상대전적`은 두 사람을 골라 기존 상대전적 모듈로 이동한다.
- 검색 탭을 바꿔도 두 입력의 선택을 유지한다. 이름을 수정하면 이전 선택을 무효화한다.
- 프로필은 통산 수상·프로필, 카테고리/연도별 전적·승률, 최근 매치, 상대 카드, 챔피언·계정으로 구성한다.
- 전체 / 내전(CK) / 대회 / 공개 큐를 제공한다. 기록이 있는 세부 큐도 선택할 수 있다.
- 카테고리·연도는 요약 전적, 최근 매치, 상대 목록에 함께 적용한다. 수상은 통산, 대회 상세 탭은 연도만, 챔피언은 카테고리별 전체 기간으로 각각 범위를 표시한다.
- 개인 기록의 상대 카드는 선택한 카테고리·연도를 비교 화면에 전달한다. 상대편 기록 없이 같은 팀으로만 만난 상대는 같은 팀 전적으로 연다.
- 비교 화면의 인물 이름은 개인 기록으로 연결된다. 상대도 주소에 보존하여 다시 비교할 때 재입력하지 않아도 된다.
- 최근 매치는 다전제를 하나로 묶고, 전체 히스토리는 20경기씩 페이지를 나눈다.

## 데이터와 구현

- `packages/ui/record-search.tsx`: 호스트와 모듈이 함께 사용하는 검색 UI. core·모듈 데이터에 직접 의존하지 않는 공통 소스.
- `packages/core/lib/db/personal.ts`: 공개 참가 기록에서 직접 개인 경기·세트 집계와 매치 히스토리를 읽는다. 조우 상대 수만큼 경기를 중복 계산하지 않는다.
- `apps/web/components/personal-records.tsx`: 카테고리·연도 필터, 승/무/패·승률, 매치 목록.
- `apps/web/app/s/[slug]/page.tsx`: 기존 프로필을 개인 기록 페이지로 확장. 기존 프로필 탭 유지.
- `packages/modules/versus/ui/`: 공통 검색, 비교 카테고리·연도, 개인 기록과의 왕복 연결.

승률은 core의 `rawWinRate`를 사용하고 무승부를 분모에서 제외한다. 경기 수에는 무승부도 포함하고 세트 수를 함께 표시한다. 수집되지 않은 기록을 채우거나 추측하지 않는다. 데이터베이스 스키마·운영 기록은 수정하지 않았다.

## 검증

- 웹·코어·모듈 타입 검사, 기존 테스트 83개, 모듈 경계 검사 통과.
- 격리된 PGlite에서 실제 SQL 검증: 다전제·무승부, 카테고리 분리, 빈 연도, 경기 단위 페이지 경계, 한국 시간 연도 경계, 숨긴 스트리머 제외.
- 브라우저에서 모드 전환 시 선택 유지, 한 명/두 명 검색, 개인 기록 ↔ 비교 왕복과 필터 유지, 없는 이름/키보드 선택, 360px 모바일 가로 넘침 확인.
- 프로덕션 빌드 확인. 기존 관리자 프레임 라우트의 파일 추적 경고는 별개로 유지된다.
