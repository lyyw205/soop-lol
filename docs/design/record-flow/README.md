# 전적 흐름 리디자인

검토: http://localhost:3001 → ‘전적 흐름’.

- 접힌 월별 그래프와 중복 지표 카드를 최근 최대 10경기의 결과 띠로 대체했다.
- 경기마다 승리자 이름, 세트 스코어, 날짜를 표시한다. 무승부는 별도 결과다.
- 결과를 누르면 대응하는 경기 상세를 열고 해당 버튼으로 스크롤·키보드 포커스를 옮긴다. 모션 줄이기 설정을 따른다.
- 최근 전적은 경기 목록의 정렬과 독립적으로 오래된 경기부터 표시한다. 같은 날의 경기들도 시각으로 정렬한다.
- 연승은 선택한 조건의 전체 경기에서 계산하며 무승부가 끊는다. 같은 팀 모드는 공동 승패와 연승·연패로 표시한다.
- 통산 그래프는 ‘통산 흐름 보기’에서 펼친다. 한 경기마다 움직이는 계단형이며 무승부는 수평이다. 카테고리·연도·맞라인 필터가 있으면 선택 조건의 전체 흐름임을 명시한다.
- 한 경기만 있으면 그래프를 생략한다. 기록이 없으면 빈 상태만 보여준다. 모바일에서 10경기는 가로로 스크롤한다.

검증:

- 흐름 계산 5개 테스트: 시각 순서/정렬 독립성, 최근 10경기, 연승, 무승부, 빈 상태.
- 웹·모듈 TypeScript, 모듈 경계, 프로덕션 빌드 통과. 기존 관리자 프레임 라우트의 파일 추적 경고 2건은 남아 있다.
- 실제 데이터 브라우저 검사: 결과 클릭 시 상세 펼침·포커스·스크롤, 목록 정렬 변경, 그래프 펼침, 같은 팀 전환, 카테고리 필터, 모바일 가로 넘침 없음. 런타임/하이드레이션 오류 없음.
- 별도 예시 데이터로 10경기, 긴 이름, 1경기, 0경기의 데스크톱·모바일 렌더링과 가로 스크롤 확인. 실제 DB에 예시 기록을 넣지 않았다.

`recent-desktop.png`, `history-desktop.png`, `history-mobile.png`는 실제 데이터 캡처다. `example-ten-980.png`, `example-ten-360.png`는 디자인 검증용 예시 데이터다.
