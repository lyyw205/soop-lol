# 로스터 빈자리 채우기

멸망전 참가 팀 표의 「미수집」 자리를 채운 경로와, **끝내 못 채운 자리** 목록. (2026-10-02)

| 순서 | 출처 | 명령 | 하는 일 |
|---|---|---|---|
| 1 | 나무위키 참가팀 표 | `scripts/fill-listed-names.mjs --all [--apply]` | 표를 자동으로 읽어 빈자리에 표시 이름(0068) |
| 2 | sooplol 1회 스냅샷(`out/sooplol/teams.ndjson`) | `scripts/fill-roster-gaps.mjs [--apply]` | 나무위키 표에 없던 팀. 아이디가 같은 연결 스트리머는 포지션을, 아니면 표시 이름 |
| 3 | 사람이 읽은 나무위키(`listed-names.json`) | `scripts/apply-listed-names.mjs [--apply]` | 자동으로 못 읽는 표 형식(2015 가로표·이벤트전 표 등)과 정정(`remove`) |

* 표시 이름은 **스트리머가 아니다** — 화면에 「미연결」로 보이고 상대전적·통계에 안 쓴다.
* 출처가 다르면 **나무위키가 우선**이다(예: 2015 불양한녀석들 원딜 — sooplol `haltol` → 나무위키 `페코2`).
* `remove` 에 적은 칸은 2단계(sooplol)를 다시 돌려도 되살아나지 않는다.

### 일부러 비워 둔 자리 — 2014 천하제패 일반인 팀원
